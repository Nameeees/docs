When PlaceholderAPI is installed, JPPrison registers the `jpprison` expansion. Use `%jpprison_<variable>%` in scoreboards, holograms, chat formats, tab lists, and any PAPI-compatible plugin.

<Note>
  PlaceholderAPI must be installed and the `jpprison` expansion loaded. If you just installed JPPrison, restart the server once to auto-register the expansion. You can verify it's active by running `/papi list` and checking for `jpprison` in the output.
</Note>

---

## Economy Placeholders

| Placeholder | Returns |
|---|---|
| `%jpprison_balance_tokens%` | Player's formatted tokens balance |
| `%jpprison_balance_tokens_raw%` | Raw numeric tokens balance |
| `%jpprison_balance_gems%` | Player's formatted gems balance |
| `%jpprison_balance_<economy>%` | Formatted balance for any custom economy |
| `%jpprison_balance_<economy>_raw%` | Raw numeric balance for any custom economy |

**Example:** To display a player's gems balance in a scoreboard line:
```
Your Gems: %jpprison_balance_gems%
```

## Pickaxe Placeholders

| Placeholder | Returns |
|---|---|
| `%jpprison_pickaxe_level%` | Current pickaxe level |
| `%jpprison_pickaxe_xp%` | Current pickaxe XP |
| `%jpprison_pickaxe_xp_needed%` | XP needed for next level |
| `%jpprison_pickaxe_prestige%` | Global prestige level |
| `%jpprison_enchant_<id>_level%` | Level of a specific enchant (e.g. `%jpprison_enchant_haste_level%`) |

**Example:** To show a player's pickaxe progress in a hologram:
```
Pickaxe Level: %jpprison_pickaxe_level%
XP: %jpprison_pickaxe_xp% / %jpprison_pickaxe_xp_needed%
Prestige: %jpprison_pickaxe_prestige%
```

## Stats & Leaderboard Placeholders

| Placeholder | Returns |
|---|---|
| `%jpprison_blocks_mined%` | Total blocks mined by this player |
| `%jpprison_top_tokens_1%` | Name of the #1 tokens holder |
| `%jpprison_top_tokens_1_value%` | Balance of the #1 tokens holder |
| `%jpprison_top_blocks_1%` | Name of the #1 blocks-mined player |

Replace `1` with `2` through `10` to access any leaderboard position. For example, `%jpprison_top_tokens_3%` returns the name of the third-place tokens holder.

**Example leaderboard scoreboard:**
```
=== Token Leaders ===
#1 %jpprison_top_tokens_1% - %jpprison_top_tokens_1_value%
#2 %jpprison_top_tokens_2% - %jpprison_top_tokens_2_value%
#3 %jpprison_top_tokens_3% - %jpprison_top_tokens_3_value%
```

## Full Variable List

The complete variable list ships in `plugins/JPPrison/placeholders-papi.txt` after the plugin loads for the first time. Open that file to see every available placeholder including any added by custom economy configurations.

<Tip>
  Use `%jpprison_balance_tokens%` in a scoreboard plugin like FeatherBoard or CMI to show live balances next to player names. Pair it with `%jpprison_pickaxe_level%` to build a compact prison-themed sidebar that updates every second.
</Tip>

JPPrison is a complete, all-in-one plugin for Minecraft Prison-gamemode servers. Instead of stitching together a dozen separate plugins to cover enchants, economies, pets, and prestige, you install one jar and get every system pre-integrated, balanced, and ready to configure. It is built for server owners who want a stable, performance-conscious foundation without spending hours chasing inter-plugin compatibility.

## What's Included

## Compatibility

JPPrison is built to run on the widest possible range of Minecraft servers.

| Requirement | Details |
|---|---|
| **Server software** | Spigot or Paper |
| **Minecraft versions** | 1.8.8 through the latest release |
| **Java** | Java 8 or newer |
| **Database** | SQLite — bundled, no external database needed |

### Optional Plugin Integrations

You do **not** need any of these to run JPPrison, but installing them unlocks additional functionality:

| Plugin | What It Enables |
|---|---|
| **WorldGuard 6.x or 7.x+** | Lets you set the `jpprison-enchants allow` region flag on your mine regions, controlling exactly where pickaxe enchants fire and rewards are granted. Both the legacy (6.x) and modern (7.x+) API are supported automatically. |
| **Vault** | Bridges one of your JPPrison economies (configurable) to Vault's economy API, so third-party shop plugins (ChestShop, EssentialsX Shop, etc.) can read and modify player balances. |
| **PlaceholderAPI** | Registers the `%jpprison_<variable>%` placeholder family, giving you access to every player stat (balance, prestige, blocks mined, active boosts, and more) in any PAPI-compatible plugin such as scoreboards, holograms, or chat formatters. |

## No Dependencies Required

JPPrison uses no NMS (net.minecraft.server) code, no Adventure/Kyori API, and no ProtocolLib. It communicates entirely through the standard Bukkit/Spigot API, which means:

- It works across all supported versions without version-specific jars or bridges.
- You do **not** need to install Adventure, ProtocolLib, or any packet library.
- Updates to Paper or Spigot rarely break compatibility.
